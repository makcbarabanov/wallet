      Сводка

      Касса — сумма счетов. Свободные собственные по AD-008 не включают кредитный лимит.

      AI режим

      Сейчас доступен только Training. Assistant — после метрик качества и отдельного AD (галочка в UI сама режим не включает).

      Отчёт Валета

      Что показывать в сводке на вкладке Валет. Выключи пункт — строка исчезнет из отчёта.

        • Интеллектуальный доклад при входе LLM пересказывает сводку в чате. Сейчас выключен — остаётся только приветствие; вопросы по-прежнему идут к Валету.
        • Сверка с банком Диагностика на вкладке Валет: выписка ↔ расходы. Только отчёт, без удаления и объединения.

        Свободные деньги

        Как показывать «доступно к тратам». Свободные собственные всегда = Касса − фонды (лимит не свои деньги).

        Фонды

        Распределение своих денег (не счета). Назначить фонду расход можно опционально при создании.
