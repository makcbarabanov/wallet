  • fundId на расходе опционален (AD-004).
  • Личный и Бизнес — разные таблицы и поля (AD-005).

✔️ Универсальный SmartSelect для всех справочниковПроверил · UI_BUILD 54 · 25.07.2026 ›
Цель
  • Пользователь не ищет элементы в длинных списках: одинаковое поведение у всех справочников.
  • Открытие поля — популярные сверху (по частоте использования); ввод — мгновенный поиск, без учёта регистра, по алиасам; нет значения — «Создать новый»; после выбора — учёт использования.
Единый компонент
  • SmartSelect({ source, searchFields, displayField, aliases, popularity, allowCreate, onCreate, onSelect }) — новые справочники подключаются настройкой, а не копированием кода.
Переведённые поля
  • Магазин — эталон; алиасы и кросс-алфавитный поиск на месте.
  • Категория — поиск с подсказками; в «Добавить расход» без значения по умолчанию (полный список по клику).
  • Расход / назначение, Объект, Заказчик — по частоте из Ledger.
  • Фикс v54: «з» не цепляет «Жура» через транслит ж→zh; «оз»→Ozon сохранён.
Границы
  • Только UX выбора. createExpense(), Gateway, Training mode, дубли и Ledger не менялись.
